## 3. SaaS productionization (QuickPlot is tenant-ready, not tenant-secure)

Built `org_id`-scoped everywhere, but **auth is intentionally absent right now** —
`X-Org-Id`/`X-Actor` are self-asserted (`quickplot/router.py` `org_of()`/`actor_of()`).

| Item | Today | The move |
|---|---|---|
| Tenancy | every `/api/v2` query `org_id`-scoped; `qp_*` tables per-tenant-aware | no schema change |
| Auth | header placeholder (`engine/dependencies.py`) | swap `org_of`/`actor_of` for Cognito deps (endpoint signatures unchanged) + pass token in `qp/ui.js` `api()` |
| Worker scale-out | in-memory `_RUNS` registry in `research.py` (single-process assumption) | seam is `start_run()`/`run_status()` only → Celery/RQ |
| Storage | `local` FS | `QP_STORAGE_BACKEND=s3` (bucket per org or org-prefixed keys); run `qp_integrity.py` on a schedule |
| Evidence | standalone `evidence_source.py` shim | read the parent's evidence `File` row in `mappers._to_file_reference` |
| Frontend | embedded slice; Users/Support/Quote are placeholders | swap `qp/app.js` nav for Mapperty's own routed nav |
| Blob integrity | digest stored per upload | periodic `MISSING`/`MISMATCH` sweep is already scripted |

**Don't** expose `/api/v2` outside a trusted network until auth is in — that's the readiness
line.

## 4. Brainstormed — new, not yet committed

Fraction of the ideas that survive contact with the codebase; nothing here is promised.

1. **Deed auto-download everywhere we already hold the plat book/page.** The clerk scrape
   already extracts plat/OR book-page cues once per order (`ctx._clerk_docs` cache). The gap
   is portal-specific *image download* logic (PDF/JPEG capture from Acclaim/Landmark/Eagle
   result pages). P2+P3 are the first 60+ counties; after that the same adapter shape pays for
   years.
2. **FEMA zone as sited evidence.** Today zone + composited map PNG are both captured. A zip
   of the FIRM panel or the NFHL JSON alongside would let QA eyeball "AE / 10-ft datum" without
   opening external links — checks the "flood insurance may be required" checklist line.
3. **NGS marks → site-control package.** We download ≤3 datasheets but the field crew wants
   the "nearest recoverable" marks ranked by distance + datasheet period. Cheap: sort + render
   one control summary PDF per order.
4. **Geocode→parcel self-healing telemetry.** `buffered_match` events are *already* tagged
   (`parcel.py:431`). Aggregating them per geocoder would let us pin which Census/ArcGIS
   results need the 75/150/300 widening — and whether the widening should shrink for some
   states.
5. **Order-level confidence score.** Per-document `Confidence` (high/medium/low/none) exists
   but isn't rolled up. A locked-set "research confidence" shown at submit time would make the
   hand-off to field survey more honest than "all locked."
6. **Change-log diffing for re-fetched documents.** The audit log records the event but not the
   content diff; storing `sha256` before/after on unlock+refetch would turn "was replaced" into
   "here's exactly what changed."
7. **Cities dropdown warm cache.** TIGERweb is live + cached, but each new county pays a first
   hit; a per-county cache file in `data/` would make dropdowns instant offline.
