G-Source logo
=============

Save the official G-Source Technologies logo here as:

    gsource-logo.png

(a PNG with a transparent or white background works best — the header shows it
on a white card).

The app loads /static/assets/gsource-logo.png automatically. If the file is
missing, the sidebar falls back to the built-in vector mark, so the app never
renders without a brand. After adding the file, just refresh the browser — no
restart needed.
